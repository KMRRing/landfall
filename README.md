# Landfall

Landfall from the Codex suite, on its own: https://kmrring.github.io/landfall/

The game's files are copied from KMRRing/Crates (`landfall.html` is the game; `index.html` is the same page, so the address opens it), without the suite's main menu or any pairing. `sw.js` keeps the game on the device for offline play.
